# Aura

A fast, native macOS terminal built for running AI coding CLIs (like Claude Code) across many long-lived sessions.

## Download & install

1. Download the latest **Aura.dmg** from [Releases](https://github.com/rmehdee/auraterm-releases/releases/latest).
2. Open the DMG and **drag Aura into Applications** (when updating, choose **Replace** — do not delete the old one; your sessions and history are kept safely outside the app).
3. First launch only: because the app is not notarized, **right-click Aura → Open**, then confirm. (A normal double-click may say it's from an unidentified developer.)

Aura checks for updates automatically and shows a banner when a newer build is available.

## Requirements

- macOS 14 (Sonoma) or later
- Apple Silicon or Intel (universal build)

## Report a bug

Use **Help → Report a Bug…** inside the app (it pre-fills your version and macOS details), or open an [issue](https://github.com/rmehdee/auraterm-releases/issues/new).
